# Modes

This directory contains different operating modes and presets for AI agents.

## Structure

- **profiles/** - Complete configuration profiles for different scenarios
- **presets/** - Quick-switch presets for common tasks
- **contexts/** - Context-specific configurations

## Mode Types

- **Development Mode** - Optimized for coding and development tasks
- **Writing Mode** - Focused on content creation and editing
- **Analysis Mode** - Data analysis and research tasks
- **Learning Mode** - Educational and tutoring scenarios
- **Custom Modes** - User-defined modes for specific workflows

## Mode Configuration

Each mode can include:
- Agent selection and configuration
- Prompt templates
- Tool availability
- MCP server configurations
- Custom instructions

## Usage

Switch between modes to optimize your AI assistant for different types of work. The installation script helps deploy mode configurations to your system.
