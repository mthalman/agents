# Agents

This directory contains custom AI agent configurations and definitions.

## Structure

- **claude/** - Claude-specific agent configurations
- **copilot/** - GitHub Copilot agent configurations
- **custom/** - Custom agent definitions

## Agent File Format

Agent files typically include:
- Agent name and description
- Capabilities and constraints
- Custom instructions
- Integration settings

## Usage

Place your agent configuration files in the appropriate subdirectory. The installation script will help deploy them to the correct system locations.
