# Development Mode Configuration

This mode optimizes the AI assistant for software development tasks.

## Configuration

### Enabled Features
- Code analysis and review
- Debugging assistance
- Documentation generation
- Refactoring suggestions
- Test generation

### Preferred Tools
- Git integration
- File system access
- Terminal/shell access
- Code search
- Language servers

### Agent Settings
- **Temperature**: 0.3 (more deterministic for code)
- **Max Tokens**: 4000
- **Code Style**: Follow project conventions
- **Testing**: Prioritize test coverage

### Prompt Enhancements
- Always consider edge cases
- Suggest error handling
- Recommend logging
- Think about security implications
- Consider performance impact

### MCP Servers
- Filesystem server (for code navigation)
- Git server (for version control)
- GitHub server (for issue/PR management)

## Usage

Activate this mode when:
- Writing or reviewing code
- Debugging issues
- Refactoring existing code
- Setting up new projects
- Working with APIs

## Tips

1. Provide context about your tech stack
2. Share relevant code snippets
3. Describe your coding standards
4. Mention any constraints or requirements
5. Ask for explanations of complex logic
