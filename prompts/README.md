# Prompts

This directory contains custom prompts for various AI tools.

## Structure

- **system/** - System-level prompts that define agent behavior
- **user/** - User prompts and templates for common tasks
- **templates/** - Reusable prompt templates

## Prompt Organization

Organize prompts by:
- Tool (claude, copilot, etc.)
- Use case (coding, writing, analysis, etc.)
- Context (work, personal, etc.)

## Usage

Store your prompts as `.txt` or `.md` files. Use descriptive filenames and include metadata comments at the top of each file.

### Example Format

```
# Prompt: [Name]
# Tool: [Claude/Copilot/etc.]
# Purpose: [Brief description]
# Tags: [tag1, tag2, tag3]

[Your prompt content here]
```
